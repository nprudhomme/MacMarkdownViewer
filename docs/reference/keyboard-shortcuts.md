# Keyboard Shortcuts

## Application

| Shortcut | Action |
|---|---|
| **Cmd+O** | Open file |
| **Shift+Cmd+O** | Open folder |
| **Cmd+N** | New window (welcome screen) |
| **Shift+Cmd+N** | Open a folder in a new window |
| **Cmd+W** | Close the current window |
| **Cmd+Q** | Quit application |

Windows are independent: each one keeps its own document, outline, search and
scroll position.

## Overlays

| Shortcut | Action |
|---|---|
| **Escape** | Close image lightbox |
| **Escape** | Close Mermaid fullscreen view |

## Theme

The theme toggle button (sun/moon icon) in the top-right corner switches between light and dark mode. The preference is persisted across sessions.
